# Flyers Flight Paths

An interactive map of where every University of Dayton men's basketball player came from —
1903–04 through 2026–27, 599 players, plus a career-scoring view.

Live: https://prolowd.github.io/flight-paths/

- `index.html` — the whole site. One self-contained file; no build step, no dependencies to install.

## Updating it

Edit `index.html` and commit. GitHub Pages redeploys in about a minute.

## Sources

Rosters from daytonflyers.com and the University of Dayton men's basketball media guide.
Career stats, positions and heights for 1947–89 from Ritter Collett's *The Flyers*;
career points for later Flyers from the media guide's all-time top 100.

Fan-made. Not affiliated with the University of Dayton.
